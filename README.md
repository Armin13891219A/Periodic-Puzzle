# پازل تعاملی جدول تناوبی عناصر 🧪

یک بازی و ابزار آموزشی تعاملی برای یادگیری و حفظ عناصر گروه‌های اصلی جدول تناوبی. این پروژه با رابط کاربری زیبا، تاریک و واکنش‌گرا طراحی شده است.

## 🔗 لینک مشاهده آنلاین (Live Demo)
**[برای شروع بازی اینجا کلیک کنید](https://Armin13891219A.github.io/Periodic-Puzzle/)**

## 🌟 ویژگی‌ها
- **دو حالت آزمون:** قابلیت حدس عناصر از روی **نماد شیمیایی** (مثال: He) یا **نام فارسی عنصر** (مثال: هلیم).
- **تمرکز بر گروه‌های اصلی:** سؤالات فقط از ۸ ستون اصلی (گروه‌های ۱، ۲، و ۱۳ تا ۱۸) استخراج می‌شود. فلزات واسطه، لانتانیدها و اکتینیدها برای حفظ ساختار علمی جدول از قبل پر شده‌اند.
- **سیستم امتیازدهی:** دارای زمان‌سنج و جان (فرصت اشتباه). به ازای هر انتخاب درست ۱۰ امتیاز مثبت و هر انتخاب اشتباه ۵ امتیاز منفی!
- **طراحی زیبا و واکنش‌گرا:** الهام گرفته شده از تم‌های مدرن و ابزارهای Tailwind CSS با پشتیبانی از Dark Mode.
- **فونت‌های اختصاصی:** استفاده از `Vazirmatn` برای متون فارسی و `Outfit` برای نمادهای انگلیسی.

## 🛠️ تکنولوژی‌های استفاده شده
- HTML5
- CSS3 (Vanilla + Tailwind CSS via CDN)
- Vanilla JavaScript (بدون نیاز به فریم‌ورک‌های سنگین)

## 📸 نحوه بازی
1. در صفحه اول، حالت آزمون (نماد یا نام) را انتخاب کرده و روی **شروع آزمون** کلیک کنید.
2. در بالای صفحه، عنصری که باید جایگاه آن را پیدا کنید نمایش داده می‌شود.
3. روی خانه خالیِ درست در جدول کلیک کنید.
4. در صورت انتخاب صحیح، خانه پر شده و عنصر بعدی نمایش داده می‌شود!
